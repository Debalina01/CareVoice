# CareVoice – Smart Medicine Reminder & Healthcare Management System

CareVoice is a healthcare management application designed to help users manage their medicines, reminders, and medical documents in one place. It provides a user-friendly interface with secure authentication and personalized data management.

## 🌐 Live Deployment

**Live Website:** https://carevoice-eb228.web.app

## ✨ Features

- User Registration and Secure Login
- Personalized Dashboard
- Medicine Management
- Medicine Reminders
- Medical Document Upload and Download
- Secure Document Access
- User-specific Data Management
- Responsive Web Interface
- Backend API Integration
- PostgreSQL Database Integration

## 🛠️ Technology Stack

| Component | Technologies |
|---|---|

| Database | PostgreSQL |
